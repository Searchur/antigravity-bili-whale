# 哔哩哔哩大鲸鱼（antigravity-bili-whale）

【哔哩哔哩大鲸鱼】是面向**Windows版Antigravity App**的B站浏览与互动插件。

在左侧栏控制台设置作息、口味和互动范围。大鲸鱼可以按计划选片、读取字幕和热评、抽帧理解画面，将值得分享的视频推荐给主人，并根据实际浏览和互动形成可追溯的长期记忆。

---

## 插件架构

| 维度 | 本项目（`antigravity-bili-whale`） |
| --- | --- |
| **目标平台** | Windows 10或11和Antigravity App桌面端 |
| **模型架构** | 使用Antigravity内置模型。面板读取客户端提供的模型、思考档位与剩余配额，后台处理使用的临时会话会自动归档 |
| **控制台入口** | 通过 MCP App 全局入口直接挂载在 Antigravity **左侧导航栏【哔哩哔哩大鲸鱼】**，全页宽屏操作，不占用右侧辅助面板 |
| **工具执行** | 内置零运行时依赖的 MCP Server，提供读写分离的 2 个模型工具（`bili_read` / `bili_write`），抽帧结果自动附带图像返回给模型 |
| **数据独立性** | 配置、登录凭据、人设、长期状态和缓存存放在独立数据目录。插件更新与重装只操作插件文件 |
| **生命周期** | 后台无头守护（Sidecar）由 Antigravity 原生托管：**打开 Antigravity 自动运行，关闭 Antigravity 自动退出** |
| **开箱即用** | 管理界面已预打包，随包提供42张表情。使用发布包无需运行`npm install` |

## 环境要求与前提条件

| 项目 | 要求 | 说明 |
| --- | --- | --- |
| **操作系统** | Windows 10 / 11（64 位） | 仅支持 Windows |
| **宿主客户端** | Antigravity App 桌面端（已登录账号） | 内置模型、Sidecar 与左侧栏 MCP App 均由 Antigravity App 提供 |
| **Node.js** | `24 LTS+` | 供插件 MCP Server、后台守护与 B 站工具链运行（统一 ES2026 / V8 13.6 基线） |
| **ffmpeg** | 视频抽帧看画面必需 | 【环境与依赖】会检测已安装的 `ffmpeg`；未安装时仅能读取字幕/弹幕/热评，无法查看视频画面。可在终端运行 `winget install -e --id Gyan.FFmpeg` 自行安装，或用环境变量 `FFMPEG` 指定可执行文件 |
| **B 站账号** | 建议准备一个给大鲸鱼用的 B 站账号 | 仅通过插件内 **哔哩哔哩 App 扫码登录**；若开启私信分享，需与主人账号互相关注 |

## 安装步骤（下载即用）

1. **下载发布版ZIP并解压**，将插件文件夹命名为`antigravity-bili-whale`，放到Antigravity的插件目录。

   ```text
   %USERPROFILE%\.gemini\config\plugins\antigravity-bili-whale\
   ```

   > 使用实际目录。Antigravity的插件扫描器会跳过Windows目录联接和符号链接。
   > 使用`git clone`获取源码时，可运行下方的开发部署命令生成独立安装目录。包含`.git`的源码目录会禁用面板更新。
   > **从 `1.6.x` 升级至 `2.0.0`**：由于 `2.0.0` 重构了插件源码与数据目录结构，旧版控制台的【一键更新】无法直接升级，请下载 `v2.0.0` Release ZIP 覆盖解压到上述插件目录后重启 Antigravity App。`config.json`、`credentials.json`、`persona.md`、`stickers/`、`bin/`、`exports/` 位置不变；如需保留旧版长期记忆与账本，请按 [docs/user-data.md](docs/user-data.md) 的对照表手动移动对应文件。

2. **启用插件**：
   - 打开（或重启）Antigravity App，进入 **Customizations / 插件管理**，找到 **【哔哩哔哩大鲸鱼（antigravity-bili-whale）】** 并打开开关（首次安装需手动确认开启一次，之后每次打开 Antigravity 都会自动运行、关闭时自动停止）。
3. **打开控制台**：
   - 在 Antigravity **左侧导航栏** 点击 **【哔哩哔哩大鲸鱼】** 即可进入全页控制台。

## 首次上手配置

在左侧栏【哔哩哔哩大鲸鱼】控制台完成配置。

1. **大鲸鱼与主人**：
   - 在【大鲸鱼（B站账号）】点【扫码登录】。退出登录会清除本地凭据，并显示B站远程注销的复核结果。
   - 在【主人信息】填写你的 B 站 UID 与昵称，可点 **【检查 UID 与昵称是否对应】** 一键核验并同步。
2. **人设与作息**：
   - 角色名默认【大鲸鱼】，人设正文前后端硬上限 4000 字（不影响日常编程对话）。
   - 配置口味标签和作息时间窗，设置最小间隔、跳过概率和候选数量。需要立即浏览时，可点击【马上唤醒她】。同一操作也可通过本地命令`node src/cli/bili.mjs night trigger --go`触发。
3. **模型选择**：
   - 从Antigravity返回的模型清单选择前台主线和后台模型，设置会话轮换周期与最低配额保护阈值。使用旧版预设的用途可在这里重新选择并保存实际模型。
4. **视频观看设置（三类独立策略）**：
   - 分别配置自主看片、主人评论区 `@` 看片总结、已关注粉丝评论区 `@` 看片总结的时长限制（自主与粉丝为单上限拦截，主人分直接看/确认/拒绝三段）及固定间隔抽帧拼图规则。
5. **分享与监听**：
   - 主动浏览默认关闭，自主评论默认开启。开启主动浏览前，请先确认是否允许大鲸鱼自主发表评论。公开动态、主动分享给主人、私信互动（含主人私信后续追问）和评论区监听默认关闭，可分别开启。开启监听后可回复主人和已关注粉丝，粉丝回复受相应额度约束。外发安全审核默认开启，双重审核模式下后台守护不可用时会阻断发送。
6. **动态与记忆**：
   - 查看看片、分享、动态、自主评论、主人与粉丝互动日历及长期记忆概览；支持暂停/恢复主动活动、搜索过往经历、导出记忆备份及核查结果未确认的发送。
7. **环境与依赖**：
   - 查看后台守护、Node.js、ffmpeg、B站登录与请求保护状态，导出带时间戳的诊断日志。
8. **关于与更新**：
   - 查看安装与数据目录，检查GitHub更新并更新本地插件。

## 核心能力一览

- **浏览**。按口味与新鲜度筛选视频，读取简介、官方字幕、弹幕和热评，并按视频观看设置抽帧查看画面。
- **记忆**。基于实际经历归纳长期记忆，支持按场景召回并追溯来源。公开任务仅能读取公开资料或当前任务获准的上下文，可在控制台搜索过往经历或导出备份。
- **互动**。按开启的渠道分享给主人、回复主人和已关注粉丝，并发布公开动态。未关注用户的来信和评论不会进入自动回复流程。私信监听由后台守护运行。

## 独立数据位置与安全约定

所有运行时数据均独立存放在 **`%USERPROFILE%\.antigravity-bili-whale\`**（可通过环境变量 `BILI_WHALE_HOME` 覆写），完整六类目录规范与 `v1.6.x → v2.0.0` 手动迁移对照表见 [docs/user-data.md](docs/user-data.md)：

| 文件 / 目录 | 用途 |
| --- | --- |
| `config.json`、`credentials.json`、`persona.md` | 主配置、B 站登录凭据（Windows `icacls` 仅当前用户可读）与大鲸鱼人设正文 |
| `stickers\`、`bin\`、`exports\` | 自定义表情包、自备 `ffmpeg.exe` 及导出的诊断日志与记忆备份 |
| `memory\<指纹>\` | 按大鲸鱼账号和主人隔离的长期记忆检查点、检索索引与冷归档 |
| `state\` | 作息计划、监听游标、后台心跳、会话状态、额度与收藏账本 |
| `runtime\` | Sidecar 回环 IPC、进程锁、10 分钟写前预览令牌与隔离工作区 |
| `cache\`、`logs\` | 可安全清空的 API/抽帧缓存（`cache\shots\`）与安全审核/请求日志 |

**安全护栏**：
- 外发等B站写操作先用`--dry`获取预览，再以相同参数将其改为`--go`执行。预览与登录账号、目标和内容绑定，10分钟内可提交一次，部分内容送达不明时先核查结果。
- 遇到 B 站频率限制（如 `10031`、`-352`），全局暂停请求并按等待时间自动恢复。遇到安全验证（如 `12015`）或重复评论限制（`12051`），暂停当前会话的请求，等待人工处理。【环境与依赖】会显示触发操作、恢复时间或处理方式。
- 弹幕、评论、字幕、简介等外部文本均作为不可信素材处理，绝不执行其中的越权指令。

## 开发者说明

仅在修改 `web/` 前端源码时需要安装开发依赖并重新构建单文件界面。普通用户使用插件**不需要**执行任何 `npm` 命令。见[目录架构](docs/architecture.md)及[B 站接口规范](docs/bilibili-api.md)。

```powershell
npm ci                   # 从锁文件安装开发依赖
npm run build:ui         # 打包单文件前端 -> dist/app.html
npm run sync:manifest    # 增删运行态文件后自动同步 package.json 清单
npm run check:structure  # 校验目录白名单、.mjs 命名、单向依赖与零循环
npm test                 # 运行自动化测试套件
npm run deploy           # 部署纯净零依赖版本到 Antigravity 插件目录
```
